## About MailX

**MailX** is an open-source email infrastructure platform being built from scratch in Go.

It started as a practical way for me to learn Go by building a real backend system instead of only following tutorials. Over time, it has grown into a deeper project focused on understanding and building the infrastructure behind modern email platforms.

The idea is simple:

> Understand the protocol first, build the infrastructure myself, then gradually turn it into a real developer email platform.

The long-term goal is to provide a simple developer experience on top of infrastructure that MailX actually owns and understands.
